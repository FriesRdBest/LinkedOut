# LinkedOut

A proof of work career application built with Python and Streamlit.

LinkedOut presents evidence, working software, decision records, and a transparent record of custom work created for real opportunities.

## Product story

LinkedOut is a working alternative to a conventional professional profile. Instead of relying on self reported skills, it connects every capability to observable proof: repositories, case studies, decision records, application artifacts, and live demonstrations.

## Architecture

- Python application layer
- Streamlit user interface
- YAML data layer for profile, projects, applications, capabilities, and decisions
- Modular data loader utilities
- Dark, responsive design system
