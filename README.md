# LinkedOut

LinkedOut is a proof of work career application built with Python and Streamlit.

It replaces a conventional professional profile with evidence, live demonstrations, decision records, and a transparent record of applications and custom work created for each opportunity.

## Purpose

LinkedOut helps a hiring manager, reporting manager, recruiter, or collaborator understand three things quickly:

1. What problems the applicant can solve.
2. How the applicant turns a problem into a working solution.
3. What evidence exists to support every claim.

The application is designed to be a credible alternative to a conventional professional profile. It presents real work, explains the thinking behind it, and makes the job search itself part of the evidence.

## Core sections

| Section | Purpose |
|---|---|
| Signal | A concise introduction to the applicant, current focus, location, work eligibility, and primary skills. |
| Operating Model | The repeatable method used to move from an operational problem to a deployed and governed solution. |
| Proof of Work | Case studies that connect real repositories, interfaces, decisions, and business value. |
| Application Ledger | A transparent record of roles pursued, custom artifacts created, application status, and learning. |
| Capability Map | Skills connected directly to repositories, demonstrations, and application artifacts. |
| Decision Records | The judgment, tradeoffs, risks, and alternatives behind important product and technical decisions. |
| Live Lab | Interactive demonstrations and links to working applications. |
| Contact | A direct way to start a conversation without relying on a conventional professional network. |

## Technology

LinkedOut is built with Python, Streamlit, YAML data files, CSS based visual styling, GitHub, and Streamlit Community Cloud.

## Operating principles

1. Evidence comes before claims.
2. Every capability should link to observable work.
3. Business value, user decisions, and technical quality matter together.
4. Artificial intelligence accelerates work, while human judgment remains accountable.
5. The application should remain clear, accessible, fast, and honest.

## Current status

Phase 1 establishes the LinkedOut foundation.

The application shell, navigation, visual direction, and page structure are now in place. Future phases will add the data layer, proof of work, application ledger, capability evidence, decision records, live demonstrations, and contact experience.
